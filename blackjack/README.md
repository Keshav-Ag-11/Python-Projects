# Blackjack Game (Python)

This is a command-line Blackjack game built using Python.

## Features

* Player vs Computer gameplay
* Hit ('y') and Stand ('n') options
* Computer automatically draws until the score reaches 17
* Win, Lose, and Draw detection
* ASCII art logo

## Files

* `blackjack.py` → main game file
* `logo.py` → ASCII art logo

## How to Run

```bash
python blackjack.py
```

## Concepts Used

* Python loops
* Functions
* Lists
* Random module
* Conditional logic
